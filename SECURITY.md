# Security policy for this fork

This fork integrates community contributions and does not currently offer a
separate security support guarantee. Integration and static checks do not
establish that a release is safe for production use.

Report suspected vulnerabilities privately using this repository's GitHub
private vulnerability reporting feature when available. If it is unavailable,
contact the repository owner through a contact method they publish. Do not
include sensitive details in a public issue before coordinating disclosure.

For vulnerabilities affecting upstream Ventoy, coordinate with the upstream
maintainers as well. This document makes no response-time commitment.
